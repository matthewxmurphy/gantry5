# Gantry 6 alpha for Grav 2

This independent Gantry 5 based alpha requires PHP 8.3–8.5, Grav 2, Admin2 and
the API plugin versions declared in blueprints.yaml. Grav retains its host
Twig/Symfony/Toolbox vendor. Grav 1.7 belongs on the Gantry 5 maintenance line.

Use an isolated testing site and matching alpha themes. Install/update manually
from https://github.com/matthewxmurphy/gantry5/releases; no automatic alpha feed
is published. Review the release's dependency migration and verification limits.
Selected-outline snapshots are not complete CMS/database/media backups.
