# Gantry 5.6.6 maintenance release

Framework SemVer: **5.6.6**. Calendar revision: **2026.11.01.001**.
Release tag: **v2026.11.01.001**. The calendar identity is recorded separately in
`RELEASE_REVISION`; existing ecosystem and CMS version comparisons continue to
use `VERSION` and `5.6.6`. The independent JavaScript build-tool version is not a
framework release identifier.

## Changes

- Correct the nullable-parameter rewriter for intersections and DNF unions,
  by-reference parameters and grouped attributes. Existing unions/nullability and
  function bodies remain unchanged; rewritten examples are parsed by actual PHP.
- Replace three deprecated legacy SCSS operator-name interpolations while
  retaining the existing dispatch names and original MIT attribution.
- Allow the shared Font Awesome 4/5 catalogues to load under the native Joomla
  and Grav markers as well as WordPress. Direct execution without a recognized
  CMS marker remains refused.
- Restore Grav's native error-service admission method. A real authenticated
  user needs both administration login and plugin-settings permission; missing,
  guest and insufficiently privileged users are refused. Grav's own error object
  and reporting configuration remain intact.
- Retain PHP `>=8.1.0 <8.5.0` in the framework dependency metadata, including PHP
  8.4. Dependency versions stay pinned; this is separate from Gantry 6's PHP 8.5,
  Twig/Symfony and theme API changes.
- Include complete inherited Gantry and bundled dependency license/notice files
  in distribution packages. Existing copyright and licensing remain applicable.

## Package and compatibility scope

Publish only the three framework archives:

- `joomla-pkg_gantry5_v5.6.6.zip`
- `wordpress-pkg_gantry5_v5.6.6.zip`
- `grav-pkg_gantry5_v5.6.6.zip`

Unchanged Helium and Hydrogen themes retain their existing versions. A normal
builder run may produce theme archives as well; those relabeled archives are not
part of this maintenance release. No installed update channel is redirected.

The native acceptance baseline is Joomla 6.2, WordPress 7.1 and Grav 1.7 with its
classic Admin plugin on PHP 8.4. Exact package-level results are recorded with
the published release. Grav 2/Admin2 belongs to the separate Gantry 6 candidate.
Earlier PHP versions retain their declared range and focused CI coverage;
third-party themes, particles and optional integrations require their own tests.
This maintenance release does not establish PHP 8.5 compatibility or certify
every advertised CMS version and extension combination.

## Installation and rollback

Keep a private backup of the site files and database and verify its restoration
before upgrading an existing site. Retain the previously installed framework
package and the site's theme/custom configuration. Install the matching platform
framework package through the native CMS installer (or Grav's normal file-install
path), then verify administration saves, frontend rendering and generated SCSS/CSS.
Use the site's tested file/database restore procedure if those checks fail; this
release does not migrate site content, switch update channels or replace themes.
