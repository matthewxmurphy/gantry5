# Gantry 6.0 development release notes

Version: **6.0.0-dev — Unreleased**. This Gantry 5 based fork is being prepared
for review. Public release and the JoomlaMafia proving-site acceptance remain
separate gates.

## PHP and dependency changes

- Set the development line's PHP range to 8.3, 8.4 and 8.5 (below 8.6),
  retaining the runtime dependency pins and adding PHP 8.5 to CI. The existing
  5.6.5 line remains available for its earlier runtime combinations.
- Remove PHP 8.5 deprecations from real cURL transfers, design-pack bitmap
  decoding, Joomla template installation and multibyte HTML attribute escaping.
  Download progress recognizes CurlHandle objects and uses fully qualified
  callbacks; unrelated stream notifications no longer report progress.
  [Runtime regressions](../tests/php85/README.md) run with diagnostics promoted
  to exceptions. These changes do not certify third-party themes or extensions.
- Correct the nullable-parameter rewriter for PHP 8.4 DNF intersections,
  by-reference parameters and grouped attributes. Existing nullable/union types
  and function bodies are preserved.
- Replace three deprecated legacy SCSS operator-name interpolations with their
  supported forms.
- Restore Grav's missing error-service admission method, using native
  authenticated-user permissions.
- Move the new WordPress/Joomla dependency line to Twig 3, Symfony 7.4 and
  Toolbox 2; move WordPress integration to Timber 2. Port the bundled Helium and
  Hydrogen PHP call sites and the framework's context, object and rendering hooks.
- Capture WordPress head/footer hooks at their existing template positions, after
  Gantry registers assets, so Timber 2 pages include their compiled CSS and scripts.
- Add a native Grav 2 Admin2 page and permission-checked API adapter for the shared
  Gantry editing tools, while keeping the CMS's own dependency vendors intact.
- Replace the framework's removed Toolbox event dispatcher with Symfony's
  dispatcher and a Gantry-owned event payload. Direct integrations must adopt
  the event-first API and updated payload types.
- Update custom Twig cache and node/parser integrations, including captured
  asset/page/Markdown output and multi-value switch cases.

Grav 2 supplies its own Twig/Symfony/Toolbox dependencies. Read
[the dependency migration guide](dependency-migration.md) before updating custom
themes, event listeners or particles. Third-party integrations require their own
acceptance with the new APIs.

## Upgrade and editing tools

- Add local compatibility preflight for the selected outline's installed theme
  and particles. Private YAML snapshots support a read-only restore preview,
  stale-state refusal and confirmed configuration restoration.
- Add section Styles controls inside Layout for matching section blueprints.
  Saving section styles preserves the unsaved Layout draft and unapplied section
  inputs. This addresses the editing request in
  [gantry/gantry5#974](https://github.com/gantry/gantry5/issues/974).
- Add a separate saved-site preview with 390, 768 and 1280 CSS-pixel viewports.
  Wide previews scroll inside their own container. The preview follows normal
  saved-site routing and page assignments.
- Add versioned visual design packs containing selected palettes, typography,
  supported installed particle placements and custom bitmaps with their full
  supplied licenses/notices. Preview checks compatibility; import creates a new
  unassigned native outline and preserves existing content and assignments.
- Add default-off approved text editing for existing native page-editing users.
  A settings administrator selects dedicated Client text instances. Fresh native
  tokens and policy/layout revisions guard each save; other Gantry actions stay
  outside the restricted interface. HTML, Twig and WordPress shortcode syntax
  remain literal text.

See [upgrade snapshots](upgrade-assistant.md), [editor tools](editor-tools.md),
[design packs](design-packs.md) and [client editing](client-editing.md) for their
supported scope and migration limits.

## Navigation and accessibility improvements

- Name and normalize the default off-canvas trigger for keyboard use.
- Add Arrow/Home/End navigation, submenu-first Escape handling and current-level
  Tab wrapping, with visible focus moved and returned through the drawer.
- Wait for dropdown visibility before moving keyboard focus; preserve correct
  Escape behavior after switching between desktop and mobile layouts.
- Keep drawer/ARIA state consistent across opposing open/close actions, clean
  detached observers, and use a cancelable touch handler with the actual event.
- Correct fractional/unitless breakpoints and back-to-top scroll-container
  handling; respect reduced-motion settings.

These changes cover concrete menu failures associated with
[gantry/gantry5#3416](https://github.com/gantry/gantry5/issues/3416).
[Frontend notes](frontend-accessibility.md) describe the tested behavior and
remaining theme/device/assistive-technology acceptance limits.

The dependency work follows the modernization request in
[gantry/gantry5#3386](https://github.com/gantry/gantry5/issues/3386).
Upstream history, authorship and existing licenses/notices are retained.
