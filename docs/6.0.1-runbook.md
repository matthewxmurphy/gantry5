# Gantry 6.0.1 installation and rollback

Developer: Matthew X Murphy, https://MatthewxMurphy.com. Support:
https://builtnotbegged.com. Existing upstream licenses remain applicable.

Gantry 6 requires PHP 8.5.x; Gantry 5.7.0 is the PHP 8.4 line. This release adds
Joomla 6.2 API client support to the existing Gantry component and uses the
already enabled Joomla core token authentication. It requires no database
schema migration, new account or token. Do not enable basic authentication.

Before installation, back up the complete site files, database and relevant
vhost/PHP configuration privately. Verify an isolated file/database restore.
Record the current Joomla, PHP, framework and theme versions. Use an isolated
staging clone; the proving Gantry 5 site is outside this release's verification.

Install the frozen framework package through Joomla's native installer.
Keep the existing migrated Gantry 6 theme selected and preserve all assignments.
Confirm the installed framework reports6.0.1. Use the same existing core token;
opening API / Swagger does not create or reset credentials.

Run the nine-route authentication checks, then create an unassigned outline,
save its layout and settings using current revisions, verify exact values in
the admin and front end, and exercise native UI saves again. Check dedicated
staging Apache/Joomla logs and PHP 8.5 FPM logs for PHP warnings/fatals. Separate
shared-host pool-capacity warnings from application errors and state any
diagnostic coverage limits honestly. Remove only acceptance-owned outlines
and any exclusively owned derived caches after evidence is captured.

For rollback, stop acceptance requests and restore the previous Gantry package
and its matching site files/configuration from the private backup. Restore the
database snapshot if outline changes must also be reverted; review any changes
since the snapshot before replacing a database. Never restore staging data
over the proving site. Verify admin and front-end rendering and recheck logs.

Release packages are manual GitHub downloads, with no automatic upstream
Gantry 5 feed. Preserve old tags and artifacts. A source checkpoint is not a
tested installed release; publish only after the documented staging pass.
