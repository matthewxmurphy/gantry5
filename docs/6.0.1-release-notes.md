## Added in Gantry core

- `GET /v1/gantry/themes/{theme}/outlines`: list installed-theme outlines.
- `POST /v1/gantry/themes/{theme}/outlines`: create a new unassigned outline.
- `GET /v1/gantry/themes/{theme}/outlines/{outline}`: read metadata/revision.
- `PATCH /v1/gantry/themes/{theme}/outlines/{outline}`: rename with revision checking.
- `DELETE /v1/gantry/themes/{theme}/outlines/{outline}`: revision-checked deletion;
  default, system and assigned outlines remain protected.
- `GET /v1/gantry/themes/{theme}/outlines/{outline}/layout`: read native layout.
- `PUT /v1/gantry/themes/{theme}/outlines/{outline}/layout`: validate/save native layout.
- `GET /v1/gantry/themes/{theme}/outlines/{outline}/settings`: read theme settings.
- `PATCH /v1/gantry/themes/{theme}/outlines/{outline}/settings`: validate/save
  selected styles, page and particle configuration groups.

Paths follow Joomla's `/api/index.php`. All operations use Joomla core Web
Services, existing core token auth and native permissions. No bridge plugin,
standalone component or parallel authentication system is installed.

## Administrator and runtime changes

- Add a visible **API / Swagger** administrator entry, interactive local
  Swagger UI 5.34.1 and an OpenAPI JSON export. The shared CMS admin entry
  documents Joomla's API; other CMS ports have request execution disabled.
- Disable Swagger's remote validator and authorization persistence; keep its
  API requests on the CMS origin. Include full upstream license/notice files.
- Fix modern browser patterns in outline titles, design-pack identifiers and
  module-position keys by escaping literal hyphens.
- Preserve PHP diagnostic reporting in the Joomla system plugin instead of
  suppressing all errors. Keep the build on its selected PHP interpreter.
- Restrict current loader, package manifests and build CI admission to PHP 8.5.

## Installation and verification

Manual packages preserve the migrated Gantry 6 dependency stack and theme
requirements. Read [API notes](core-api.md), [migration guidance](dependency-migration.md)
and the [installation/rollback runbook](6.0.1-runbook.md). The Gantry 5 line is
unchanged. This release does not provide an API transport for WordPress/Grav or
certify arbitrary third-party themes. Final staging results are recorded with
the release and on task341; source-only checks are not staging acceptance.

Native admin writers do not share the API write lock. Native multi-file layout
saves/events retain their existing I/O recovery limits; this release does not
add a database/filesystem transaction. Use the documented backup/rollback path.
